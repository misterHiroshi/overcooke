# オーバークック風協力調理ゲーム 設計書

## 1. 概要

- ジャンル: リアルタイム協力調理アクション（オーバークック2型）
- プラットフォーム: Web（ブラウザ）
- 技術: Vite + TypeScript + Phaser3（クライアント）/ Node.js + Socket.io（サーバー）
- プレイ人数: 1〜2人（協力プレイ、同一部屋に接続）
- 参考: オーバークック2 (https://www.pckt.co.jp/overcooked2/)

## 2. ゲームルール

- キッチン内で注文された料理を制限時間内に完成させ提供口へ届ける
- 料理 = レシピ通りの手順（切る→焼く/茹でる→皿に盛る→提供）
- 注文は一定間隔で発生、放置しすぎるとペナルティ（減点/注文消滅）
- 制限時間内の合計スコアで結果判定
- 2人プレイ時は同一キッチンを共有、作業分担で効率化（例: 片方が切る係、片方が運搬・提供係）

## 3. コア機能一覧

| 機能 | 内容 |
|---|---|
| キャラクター移動 | 上下左右移動、向き管理 |
| 拾う/持つ/置く | 食材・皿・調理器具を1つだけ持てる |
| 切る | まな板上でインタラクトキー連打 or 長押しでカット完了 |
| 加熱調理 | コンロ/フライパンに具材を乗せ、時間経過で完成。焦げ要素あり |
| 盛り付け | 完成具材を皿に乗せる |
| 提供 | 完成皿を提供口に置く→注文とマッチング→スコア加算 |
| 注文管理 | 注文キュー表示、残り時間バー |
| スコア/タイマー | ゲーム全体の制限時間、スコア表示 |
| マルチプレイ同期 | 2人の位置・持ち物・オブジェクト状態をサーバー経由で同期 |

## 4. マップ/オブジェクト設計

タイルベースマップ（Tiledマップエディタ形式 or 自前JSON）。

配置オブジェクト:
- 食材置き場（在庫無限のスポーンポイント）
- まな板（切る台）
- コンロ（加熱調理）
- 皿置き場
- 提供口（カウンター）
- ゴミ箱（失敗品廃棄）
- 通路/障害物

## 5. アーキテクチャ

### 5.1 全体構成

```
[クライアントA] <-- WebSocket --> [Node.jsサーバー] <-- WebSocket --> [クライアントB]
     Phaser3                    Socket.io + ゲームロジック            Phaser3
     (描画・入力のみ)              (状態の唯一の正解=サーバー権威)
```

- **サーバー権威モデル**採用（チート防止・状態不整合防止のため）
  - クライアントは入力（移動方向、インタラクトキー押下）のみ送信
  - サーバーが全プレイヤー位置・オブジェクト状態を計算し、tickごとに全クライアントへブロードキャスト
  - クライアントは受信状態を描画するのみ（必要なら簡易補間で滑らかに見せる）

### 5.2 通信設計

- プロトコル: Socket.io（WebSocket、再接続処理が楽）
- ルーム機能でキッチンごとに部屋分け（部屋コード発行 or URL共有）
- 送信頻度: サーバー→クライアント 状態ブロードキャストは20Hz目安（初期実装は10Hzでも可）
- クライアント→サーバー: 入力イベント都度送信（キー押下/離す、インタラクト）

### 5.3 状態管理（サーバー側）

```
GameState {
  players: { id, x, y, facing, holding: ItemId | null }[]
  stations: { id, type, contents, progress, state }[]
  orders: { id, recipe, timeLeft }[]
  score: number
  timeLeft: number
}
```

## 6. 開発ステップ（段階的実装）

1. 雛形構築（Vite+TS+Phaser、ローカル起動確認）
2. 1キャラ移動（ローカル、単一プレイヤーのみ）
3. 調理設備配置（まな板・コンロ・提供口・食材置き場をマップに配置）
4. 1レシピ動作（切る→焼く→盛る→提供の最小フロー、ローカル完結）
5. 注文システム（制限時間・スコア）
6. マルチプレイ基盤（Node.js+Socket.ioサーバー構築、部屋作成、状態ブロードキャスト）
7. 2人協力プレイ（入力→サーバー反映→両クライアント描画同期）
8. デプロイ（Hostinger VPS、Traefik経由でWebSocket対応必要）

## 7. 未決定事項（後で決める）
